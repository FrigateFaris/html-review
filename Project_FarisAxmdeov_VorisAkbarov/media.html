Multimedia

These tags add rich content: figures with captions, responsive images, other pages, drawings and subtitles.

  • <figure> and <figcaption>
  • <picture>
  • <iframe>
  • <embed>
  • <svg>
  • <canvas>
  • <track>

<figure> and <figcaption>

Definition

figure groups an image (or a diagram, code...) with its caption figcaption.

Attributes

AttributeRole
(none)Only global attributes.

Example (code)

<figure>
  <img src="images/photo.svg" alt="Landscape" width="300" height="200">
  <figcaption>Figure 1 &ndash; A landscape</figcaption>
</figure>

Example (result)

<picture>

Definition

Gives several versions of an image; the browser chooses the best one for the screen size.

Attributes

AttributeRole
(none)It contains source tags and one img.
srcset (on source)Image file to use.
media (on source)Screen condition, e.g. (max-width: 600px).

Example (code)

<picture>
  <source srcset="images/photo-small.svg" media="(max-width: 600px)">
  <img src="images/photo.svg" alt="Responsive landscape" width="300" height="200">
</picture>

Example (result)

<iframe>

Definition

Displays another web page inside the current page (for example a YouTube video or a map).

Attributes

AttributeRole
srcURL of the page to show.
width / heightSize of the frame.
titleDescription of the content (accessibility).
allowfullscreenAllows full screen mode.

Example (code)

<iframe src="lists.html" width="400" height="200" title="Lists page"></iframe>

Example (result)

<embed>

Definition

Inserts external content such as a PDF or an image. It is an empty tag.

Attributes

AttributeRole
srcPath of the file.
typeFormat of the file.
width / heightSize of the content.

Example (code)

<embed src="images/logo.svg" type="image/svg+xml" width="80" height="80">

Example (result)

<svg>

Definition

Draws vector graphics (shapes, lines, text) directly in the page.

Attributes

AttributeRole
width / heightSize of the drawing.
viewBoxCoordinate system of the drawing.

Example (code)

<svg width="200" height="100" viewBox="0 0 200 100">
  <rect x="10" y="10" width="80" height="80" fill="#2c3e50"></rect>
  <circle cx="150" cy="50" r="40" fill="#e67e22"></circle>
</svg>

Example (result)

<canvas>

Definition

A drawing area. The drawing is made with JavaScript. The text inside is shown if canvas is not supported.

Attributes

AttributeRole
width / heightSize of the drawing area.
idName used by JavaScript to draw.

Example (code)

<canvas id="myCanvas" width="200" height="80">
  Your browser does not support canvas.
</canvas>

Example (result)

Your browser does not support canvas.

<track>

Definition

Adds subtitles or captions to a video. It is placed inside the video tag.

Attributes

AttributeRole
srcPath of the subtitle file (.vtt).
kindsubtitles, captions...
srclangLanguage of the subtitles.
labelName shown in the menu.
defaultSubtitles shown by default.

Example (code)

<video controls width="320">
  <source src="images/video.mp4" type="video/mp4">
  <track src="images/subtitles.vtt" kind="subtitles" srclang="en" label="English" default>
</video>
