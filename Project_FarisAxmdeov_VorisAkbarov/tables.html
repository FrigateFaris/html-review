Tables

Tables show data in rows and columns.

  • <table>
  • <tr>
  • <th> and <td>
  • <caption>
  • <thead>, <tbody>, <tfoot>

<table>

Definition

Creates a table. It contains rows (tr) with cells (th or td).

Attributes

AttributeRole
borderOld attribute for borders (use CSS instead).
class / idUsed to style the table with CSS.

Example (code)

<table class="demo-table">
  <tr>
    <td>Cell 1</td>
    <td>Cell 2</td>
  </tr>
</table>

Example (result)

Cell 1 Cell 2

<tr>

Definition

A table row.

Attributes

AttributeRole
(none)Only global attributes.

Example (code)

<table class="demo-table">
  <tr>
    <td>Row 1</td>
  </tr>
  <tr>
    <td>Row 2</td>
  </tr>
</table>

Example (result)

Row 1
Row 2

<th> and <td>

Definition

th is a header cell (bold and centered); td is a normal data cell.

Attributes

AttributeRole
colspanNumber of columns the cell covers.
rowspanNumber of rows the cell covers.
scopeFor th: says if it is the header of a row or a col.

Example (code)

<table class="demo-table">
  <tr>
    <th scope="col">Day</th>
    <th scope="col">Course</th>
  </tr>
  <tr>
    <td rowspan="2">Monday</td>
    <td>HTML</td>
  </tr>
  <tr>
    <td>CSS</td>
  </tr>
  <tr>
    <td colspan="2">Weekend: no course</td>
  </tr>
</table>

Example (result)

Day Course
Monday HTML
CSS
Weekend: no course

<caption>

Definition

The title of a table. It is written just after <table>.

Attributes

AttributeRole
(none)Only global attributes.

Example (code)

<table class="demo-table">
  <caption>My timetable</caption>
  <tr>
    <td>Monday</td>
    <td>HTML</td>
  </tr>
</table>

Example (result)

My timetable
Monday HTML

<thead>, <tbody>, <tfoot>

Definition

Group the rows of a table: header part, body part and footer part.

Attributes

AttributeRole
(none)Only global attributes.

Example (code)

<table class="demo-table">
  <caption>Students' marks</caption>
  <thead>
    <tr>
      <th>Name</th>
      <th>HTML</th>
      <th>CSS</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Ali</td>
      <td>16</td>
      <td>14</td>
    </tr>
    <tr>
      <td>Sara</td>
      <td>18</td>
      <td>17</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <td>Average</td>
      <td>17</td>
      <td>15.5</td>
    </tr>
  </tfoot>
</table>

Example (result)

Students' marks
Name HTML CSS
Ali 16 14
Sara 18 17
Average 17 15.5
