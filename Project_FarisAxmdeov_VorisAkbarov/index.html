Home & Page Structure

Welcome to our HTML review website. Every page presents one family of tags with its definition, its attributes and an example. This first page explains the basic structure of every HTML document.

  • <!DOCTYPE html>
  • <html>
  • <head>
  • <body>
  • <!-- comment -->

<!DOCTYPE html>

Definition

The document type declaration. It is the first line of every page and tells the browser to use the HTML5 standard.

Attributes

AttributeRole
htmlDeclares the HTML5 document type (no other value is needed).

Example (code)

<!DOCTYPE html>

Example (result)

This tag is not displayed in the page: it only gives structure or information to the browser.

<html>

Definition

The root element. It contains all the other elements of the page.

Attributes

AttributeRole
langLanguage of the page content (e.g. en, fr).
dirText direction: ltr or rtl.

Example (code)

<html lang="en">
  ...
</html>

Example (result)

This tag is not displayed in the page: it only gives structure or information to the browser.

<head>

Definition

Contains information about the page (title, metadata, links to CSS). Its content is not shown in the page.

Attributes

AttributeRole
(none)Only global attributes; it contains title, meta, link, script.

Example (code)

<head>
  <meta charset="UTF-8">
  <title>My page</title>
  <link rel="stylesheet" href="css/style.css">
</head>

Example (result)

This tag is not displayed in the page: it only gives structure or information to the browser.

<body>

Definition

Contains all the visible content of the page: text, images, links, tables, forms...

Attributes

AttributeRole
id / classIdentify or group the element for CSS.
onloadScript that runs when the page is loaded.

Example (code)

<body>
  <h1>Hello world</h1>
  <p>My first web page.</p>
</body>

Example (result)

Hello world

My first web page.

<!-- comment -->

Definition

A comment. It is used to write notes in the code; the browser does not display it.

Attributes

AttributeRole
(none)Comments have no attributes.

Example (code)

<p>Visible text</p>
<!-- This comment is not visible -->

Example (result)

Visible text
