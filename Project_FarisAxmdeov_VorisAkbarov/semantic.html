Semantic & Layout Tags

Semantic tags describe the role of each part of the page. They help search engines, screen readers and developers. The example below shows a full page layout.

  • Full layout
  • <header>
  • <nav>
  • <main>
  • <section>
  • <article>
  • <aside>
  • <footer>
  • <div>
  • <address>
  • <time>
  • <details> and <summary>

Full layout

Definition

A typical page built with semantic tags.

Attributes

AttributeRole
(none)Each part is styled with CSS Flexbox.

Example (code)

<div class="layout-demo">
  <header>header</header>
  <nav>nav</nav>
  <div class="layout-middle">
    <main>
      <article>article
        <section>section</section>
      </article>
    </main>
    <aside>aside</aside>
  </div>
  <footer>footer</footer>
</div>

Example (result)

header
nav
article
section
aside
footer

<header>

Definition

The top part of a page or of a section: logo, title, menu.

Attributes

AttributeRole
(none)Only global attributes.

Example (code)

<header>
  <h3>My Website</h3>
  <p>Learn HTML</p>
</header>

Example (result)

My Website

Learn HTML

<nav>

Definition

A block of navigation links (the menu).

Attributes

AttributeRole
(none)Only global attributes.

Example (code)

<nav>
  <a href="index.html">Home</a> |
  <a href="text.html">Text</a> |
  <a href="forms.html">Forms</a>
</nav>

Example (result)

Home | Text | Forms

<main>

Definition

The main content of the page. There is only one main per page.

Attributes

AttributeRole
(none)Only global attributes.

Example (code)

<main>
  <p>The main content goes here.</p>
</main>

Example (result)

The main content goes here.

<section>

Definition

A part of the page about one topic, usually with a title.

Attributes

AttributeRole
(none)Only global attributes.

Example (code)

<section>
  <h3>Our courses</h3>
  <p>HTML, CSS and JavaScript.</p>
</section>

Example (result)

Our courses

HTML, CSS and JavaScript.

<article>

Definition

Independent content that has a meaning alone: a blog post, a news article, a comment.

Attributes

AttributeRole
(none)Only global attributes.

Example (code)

<article>
  <h3>New course</h3>
  <p>The HTML course starts on Monday.</p>
</article>

Example (result)

New course

The HTML course starts on Monday.

<aside>

Definition

Content related to the main content but separate: a sidebar, a tip, ads.

Attributes

AttributeRole
(none)Only global attributes.

Example (code)

<aside>
  <p><strong>Tip:</strong> always close your tags.</p>
</aside>

Example (result)

Tip: always close your tags.

<footer>

Definition

The bottom part of a page or section: copyright, contact, links.

Attributes

AttributeRole
(none)Only global attributes.

Example (code)

<footer>
  <p>&copy; 2026 My Website</p>
</footer>

Example (result)

© 2026 My Website

<div>

Definition

A block container without meaning, used to group elements for layout with CSS.

Attributes

AttributeRole
className used by CSS.
idUnique name.

Example (code)

<div class="box">
  <p>Content inside a div.</p>
</div>

Example (result)

Content inside a div.

<address>

Definition

Contact information of the author or owner.

Attributes

AttributeRole
(none)Only global attributes.

Example (code)

<address>
  Written by Ali and Sara<br>
  <a href="mailto:info.moumni.nourchen@gmail.com">info.moumni.nourchen@gmail.com</a>
</address>

Example (result)

Written by Ali and Sara
info.moumni.nourchen@gmail.com

<time>

Definition

A date or a time, readable by computers.

Attributes

AttributeRole
datetimeThe date/time in machine format, e.g. 2026-10-02.

Example (code)

<p>The exam is on <time datetime="2026-10-15">October 15</time>.</p>

Example (result)

The exam is on October 15.

<details> and <summary>

Definition

details is a box that the user can open or close; summary is its visible title.

Attributes

AttributeRole
openThe box is open by default (on details).

Example (code)

<details>
  <summary>Show the answer</summary>
  <p>HTML means HyperText Markup Language.</p>
</details>

Example (result)

Show the answer

HTML means HyperText Markup Language.
