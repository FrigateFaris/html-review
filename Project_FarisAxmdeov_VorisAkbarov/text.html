Text Formatting Tags

These tags are used to write titles, paragraphs and to give a meaning or a style to words.

  • <h1> ... <h6>
  • <p>
  • <br>
  • <hr>
  • <strong> and <b>
  • <em> and <i>
  • <mark>
  • <small>
  • <sub> and <sup>
  • <del> and <ins>
  • <blockquote>
  • <q>
  • <abbr>
  • <code> and <pre>
  • <span>

<h1> ... <h6>

Definition

Headings. h1 is the most important title, h6 the least important.

Attributes

AttributeRole
idUnique name, useful for links to this title.
classGroups elements for CSS.

Example (code)

<h1>Heading 1</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>
<h6>Heading 6</h6>

Example (result)

Heading 1

Heading 2

Heading 3

Heading 6

<p>

Definition

A paragraph of text.

Attributes

AttributeRole
titleTooltip shown when the mouse is over the paragraph.
classGroups elements for CSS.

Example (code)

<p title="A paragraph">This is a paragraph of text.</p>

Example (result)

This is a paragraph of text.

<br>

Definition

A line break inside a text. It is an empty tag (no closing tag).

Attributes

AttributeRole
(none)Only global attributes.

Example (code)

<p>First line<br>Second line</p>

Example (result)

First line
Second line

<hr>

Definition

A horizontal line that separates two parts of the content. It is an empty tag.

Attributes

AttributeRole
(none)Only global attributes; the look is changed with CSS.

Example (code)

<p>Part one</p>
<hr>
<p>Part two</p>

Example (result)

Part one

Part two

<strong> and <b>

Definition

strong marks important text (bold); b makes text bold without extra importance.

Attributes

AttributeRole
(none)Only global attributes.

Example (code)

<p><strong>Warning:</strong> this is important. <b>Bold text</b>.</p>

Example (result)

Warning: this is important. Bold text.

<em> and <i>

Definition

em stresses a word (italic); i writes text in italic (technical term, foreign word).

Attributes

AttributeRole
(none)Only global attributes.

Example (code)

<p>I <em>really</em> like HTML. <i>Bonjour</i> means hello.</p>

Example (result)

I really like HTML. Bonjour means hello.

<mark>

Definition

Highlights a part of the text.

Attributes

AttributeRole
(none)Only global attributes.

Example (code)

<p>Do not forget the <mark>closing tag</mark>.</p>

Example (result)

Do not forget the closing tag.

<small>

Definition

Writes smaller text, such as a legal note.

Attributes

AttributeRole
(none)Only global attributes.

Example (code)

<p>Price: 100$ <small>(taxes not included)</small></p>

Example (result)

Price: 100$ (taxes not included)

<sub> and <sup>

Definition

sub writes text below the line (subscript); sup writes text above the line (superscript).

Attributes

AttributeRole
(none)Only global attributes.

Example (code)

<p>H<sub>2</sub>O and 10<sup>2</sup> = 100</p>

Example (result)

H2O and 102 = 100

<del> and <ins>

Definition

del shows deleted text (crossed out); ins shows inserted text (underlined).

Attributes

AttributeRole
citeURL that explains the change.
datetimeDate and time of the change.

Example (code)

<p>Price: <del>50$</del> <ins datetime="2026-10-01">35$</ins></p>

Example (result)

Price: 50$ 35$

<blockquote>

Definition

A long quotation taken from another source, displayed as an indented block.

Attributes

AttributeRole
citeURL of the source of the quotation.

Example (code)

<blockquote cite="https://www.w3.org/">
  The Web is for everyone.
</blockquote>

Example (result)

The Web is for everyone.

<q>

Definition

A short quotation inside a sentence. The browser adds quotation marks.

Attributes

AttributeRole
citeURL of the source of the quotation.

Example (code)

<p>The teacher said: <q>Always close your tags</q>.</p>

Example (result)

The teacher said: Always close your tags.

<abbr>

Definition

An abbreviation. The full meaning appears when the mouse is over it.

Attributes

AttributeRole
titleFull meaning of the abbreviation.

Example (code)

<p><abbr title="HyperText Markup Language">HTML</abbr> is easy.</p>

Example (result)

HTML is easy.

<code> and <pre>

Definition

code shows computer code; pre keeps spaces and line breaks exactly as they are written.

Attributes

AttributeRole
(none)Only global attributes.

Example (code)

<pre><code>let x = 5;
console.log(x);</code></pre>

Example (result)

let x = 5;
console.log(x);

<span>

Definition

An inline container without meaning, used to style a small part of a text with CSS.

Attributes

AttributeRole
className used by CSS to style the text.
idUnique name of the element.

Example (code)

<p>This word is <span class="highlight">styled</span> with CSS.</p>

Example (result)

This word is styled with CSS.
