Page 4 – Lists

Lists organize information as items. HTML has unordered, ordered and description lists.

  • <ul>
  • <ol>
  • <li>
  • Nested lists
  • <dl>, <dt>, <dd>

<ul>

Definition

An unordered list: items are shown with bullets.

Attributes

AttributeRole
(none)Only global attributes; bullet style is changed with CSS list-style-type.

Example (code)

<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

Example (result)

  • HTML
  • CSS
  • JavaScript

<ol>

Definition

An ordered list: items are numbered.

Attributes

AttributeRole
typeKind of numbering: 1, A, a, I, i.
startFirst number of the list.
reversedCounts down instead of up.

Example (code)

<ol type="A" start="3">
  <li>Open VS Code</li>
  <li>Write the code</li>
  <li>Test with Live Server</li>
</ol>

Example (result)

  1. Open VS Code
  2. Write the code
  3. Test with Live Server

<li>

Definition

A list item. It is used inside ul or ol.

Attributes

AttributeRole
valueNumber of this item (only inside ol).

Example (code)

<ol>
  <li>First</li>
  <li value="10">Tenth</li>
  <li>Eleventh</li>
</ol>

Example (result)

  1. First
  2. Tenth
  3. Eleventh

Nested lists

Definition

A list can be placed inside an li to create sub-items.

Attributes

AttributeRole
(none)Uses the attributes of ul, ol and li.

Example (code)

<ul>
  <li>Front-end
    <ul>
      <li>HTML</li>
      <li>CSS</li>
    </ul>
  </li>
  <li>Back-end</li>
</ul>

Example (result)

  • Front-end
    • HTML
    • CSS
  • Back-end

<dl>, <dt>, <dd>

Definition

A description list: dt is the term and dd its description.

Attributes

AttributeRole
(none)Only global attributes.

Example (code)

<dl>
  <dt>HTML</dt>
  <dd>Language that gives the structure of a page.</dd>
  <dt>CSS</dt>
  <dd>Language that gives the style of a page.</dd>
</dl>

Example (result)

HTML
Language that gives the structure of a page.
CSS
Language that gives the style of a page.
