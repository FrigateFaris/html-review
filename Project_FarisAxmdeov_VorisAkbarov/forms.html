Forms

Forms let the user enter information and send it to a server.

  • <form>
  • <label>
  • <input>
  • <textarea>
  • <select> and <option>
  • <button>
  • <fieldset> and <legend>
  • <datalist>

<form>

Definition

A container for input fields. It sends the data when the user submits it.

Attributes

AttributeRole
actionURL where the data is sent.
methodHow the data is sent: get or post.
nameName of the form.

Example (code)

<form action="#" method="post">
  <input type="text" name="city" placeholder="Your city">
  <button type="submit">Send</button>
</form>

Example (result)

<label>

Definition

A text that describes a field. Clicking it selects the field.

Attributes

AttributeRole
forThe id of the field it is linked to.

Example (code)

<label for="user">Username:</label>
<input type="text" id="user" name="user">

Example (result)

<input>

Definition

A field to enter data. Its kind depends on the type attribute. It is an empty tag.

Attributes

AttributeRole
typeKind of field: text, email, password, number, date, checkbox, radio, file, submit...
nameName of the data sent to the server.
valueDefault value.
placeholderGrey help text in the empty field.
requiredThe field must be filled.
min / maxMinimum and maximum values.

Example (code)

<form action="#">
  <p><label for="em">E-mail:</label> <input type="email" id="em" name="email" placeholder="name@mail.com" required></p>
  <p><label for="pw">Password:</label> <input type="password" id="pw" name="pw"></p>
  <p><label for="age">Age:</label> <input type="number" id="age" name="age" min="10" max="99"></p>
  <p><label for="bd">Birthday:</label> <input type="date" id="bd" name="bd"></p>
  <p><input type="checkbox" id="news" name="news"> <label for="news">Newsletter</label></p>
  <p><input type="radio" id="m" name="g" value="m"> <label for="m">Male</label>
     <input type="radio" id="f" name="g" value="f"> <label for="f">Female</label></p>
  <p><input type="submit" value="Send"> <input type="reset" value="Reset"></p>
</form>

Example (result)

<textarea>

Definition

A field for long text on several lines.

Attributes

AttributeRole
rows / colsHeight and width in lines and characters.
nameName of the data.
placeholderHelp text.
maxlengthMaximum number of characters.

Example (code)

<label for="msg">Message:</label><br>
<textarea id="msg" name="msg" rows="4" cols="40" placeholder="Write your message"></textarea>

Example (result)


<select> and <option>

Definition

A drop-down list. Each choice is an option.

Attributes

AttributeRole
nameName of the data (on select).
multipleAllows several choices (on select).
valueValue sent to the server (on option).
selectedOption chosen by default.

Example (code)

<label for="lang">Language:</label>
<select id="lang" name="lang">
  <option value="en">English</option>
  <option value="fr" selected>French</option>
  <option value="ar">Arabic</option>
</select>

Example (result)

<button>

Definition

A clickable button.

Attributes

AttributeRole
typesubmit (send the form), reset (empty the form) or button (no action).
disabledThe button cannot be clicked.

Example (code)

<button type="button">Click me</button>
<button type="button" disabled>Disabled</button>

Example (result)

<fieldset> and <legend>

Definition

fieldset groups related fields in a box; legend is the title of the box.

Attributes

AttributeRole
disabledDisables all the fields of the group (on fieldset).

Example (code)

<fieldset>
  <legend>Personal information</legend>
  <label for="fn">First name:</label>
  <input type="text" id="fn" name="fn">
</fieldset>

<datalist>

Definition

A list of suggestions for an input field.

Attributes

AttributeRole
idName used by the list attribute of the input.

Example (code)

<label for="br">Browser:</label>
<input list="browsers" id="br" name="br">
<datalist id="browsers">
  <option value="Chrome">
  <option value="Firefox">
  <option value="Edge">
</datalist>
