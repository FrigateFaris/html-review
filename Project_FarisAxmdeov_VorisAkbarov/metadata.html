Metadata

Metadata tags are written in the <head>. They give information about the page to the browser and to search engines. They are not displayed in the page.

  • <title>
  • <meta charset>
  • <meta name>
  • <meta http-equiv>
  • <link>
  • <base>
  • <script>
  • <style>

<title>

Definition

The title of the page, shown in the browser tab and in search results.

Attributes

AttributeRole
(none)Only global attributes.

Example (code)

<title>Metadata | HTML Review</title>

Example (result)

Look at the browser tab: it shows “Metadata | HTML Review”.

<meta charset>

Definition

Gives the character encoding of the page. UTF-8 displays all languages and symbols.

Attributes

AttributeRole
charsetEncoding of the page, usually UTF-8.

Example (code)

<meta charset="UTF-8">

Example (result)

Thanks to UTF-8 we can show: é à ç — Привет — مرحبا — ✓

<meta name>

Definition

Gives information about the page: description, author, keywords, viewport for mobiles.

Attributes

AttributeRole
nameKind of information: description, author, keywords, viewport.
contentValue of the information.

Example (code)

<meta name="description" content="Review of the main HTML tags">
<meta name="author" content="Ali, Sara">
<meta name="keywords" content="HTML, tags, review">
<meta name="viewport" content="width=device-width, initial-scale=1.0">

Example (result)

This tag is not displayed in the page: it only gives structure or information to the browser.

<meta http-equiv>

Definition

Gives an instruction to the browser, for example refresh the page.

Attributes

AttributeRole
http-equivKind of instruction, e.g. refresh.
contentValue, e.g. number of seconds.

Example (code)

<meta http-equiv="refresh" content="30">

Example (result)

This tag is not displayed in the page: it only gives structure or information to the browser.

<link>

Definition

Links the page to an external file: a CSS stylesheet or an icon.

Attributes

AttributeRole
relRelation: stylesheet, icon...
hrefPath of the file.
typeFormat of the file.

Example (code)

<link rel="stylesheet" href="css/style.css">
<link rel="icon" href="images/logo.svg" type="image/svg+xml">

Example (result)

This page uses css/style.css: all colors and the layout you see come from it.

<base>

Definition

Gives the base URL used by all the relative links of the page.

Attributes

AttributeRole
hrefBase URL.
targetDefault target of all links.

Example (code)

<base href="https://example.com/" target="_blank">

Example (result)

This tag is not displayed in the page: it only gives structure or information to the browser.

<script>

Definition

Adds JavaScript code, written inside or in an external file.

Attributes

AttributeRole
srcPath of the external .js file.
deferRuns the script after the page is loaded.
asyncLoads the script in parallel.

Example (code)

<script src="js/main.js" defer></script>

Example (result)

This tag is not displayed in the page: it only gives structure or information to the browser.

<style>

Definition

Writes CSS inside the page. In this project we do not use it: all CSS is in css/style.css.

Attributes

AttributeRole
mediaScreen type where the CSS is applied.

Example (code)

<style>
  p { color: blue; }
</style>

Example (result)

Not used in this project (rule: all CSS goes in style.css).
