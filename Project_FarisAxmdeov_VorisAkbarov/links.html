Links, Image, Video & Audio

These tags connect pages together and add pictures, sound and video to a web page. Click on a button below to view the topic:

Links Image Video Audio

<a> (Links)

Definition

A hyperlink. It opens another page, a website, an e-mail or a part of the same page.

Attributes

AttributeRole
hrefAddress (URL) of the destination.
targetWhere to open the link: _blank = new tab.
titleTooltip text.
downloadDownloads the file instead of opening it.

Example (code)

<a href="lists.html">Internal link: Lists page</a><br>
<a href="https://www.w3schools.com" target="_blank">External link: W3Schools</a><br>
<a href="mailto:info.moumni.nourchen@gmail.com">Send an e-mail</a><br>
<a href="#top">Link to the top of the page</a>

Example (result)

Internal link: Lists page
External link: W3Schools
Send an e-mail
Link to the top of the page

<img> (Image)

Definition

Displays an image. It is an empty tag.

Attributes

AttributeRole
srcPath of the image file.
altAlternative text if the image cannot be shown.
width / heightSize of the image in pixels.
titleTooltip text.

Example (code)

<img src="images/photo.svg" alt="A landscape" width="300" height="200" title="Landscape">

Example (result)

<video> (Video)

Definition

Plays a video file in the page.

Attributes

AttributeRole
srcPath of the video file.
controlsShows the video buttons.
width / heightSize of the video.
posterImage shown before the video starts.
autoplay / loop / mutedAutomatic start, repeat, no sound.

Example (code)

<video controls width="320" poster="images/photo.svg">
  <source src="images/video.mp4" type="video/mp4">
  Your browser does not support video.
</video>

Example (result)

<source>

Gives one file (and its format) for an audio or video element. The browser chooses the first one it can read.

<audio> (Audio)

Definition

Plays a sound file in the page.

Attributes

AttributeRole
srcPath of the audio file.
controlsShows play, pause and volume buttons.
autoplayStarts the sound automatically.
loopPlays the sound again and again.
mutedStarts without sound.

Example (code)

<audio controls>
  <source src="images/audio.mp3" type="audio/mpeg">
  <source src="images/audio.wav" type="audio/wav">
  Your browser does not support audio.
</audio>
